# FlyRank

FlyRank is a capstone project built with React, Vite, Tailwind CSS, and TypeScript.

## About

The current frontend includes an accessible account settings form for profile details,
appearance, and email notifications. Settings are saved locally in the current browser;
there is no backend integration yet.

## Getting started

Requires Node.js and npm.

```sh
npm install
npm run dev
```

To create a production build:

```sh
npm run build
```
